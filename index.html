Catatan dan batasan tiap menu dikumpulkan di sini supaya menu tetap ringkas.

Item Pouch & Gunner Pouch

Pilih pouch, cari item, pilih slot (1–8) dan jumlah, lalu ketuk Isi atau ubah slot. Item Pouch 1–3 = tiga halaman item pouch, Gunner Pouch = kantong amunisi. Item di sini tidak mengurangi Item Box.

Hapus massal

Tombol di bawah mengosongkan isi menu. Perubahan baru tersimpan setelah Simpan & unduh file, dan Reset semua perubahan bisa membatalkannya.

Equipment Box

Nama armor Waist sudah dikoreksi: daftar upstream mh4edit kehilangan 11 nama di awal, jadi ID Waist = nomor urut daftar + 11 (dicocokkan dengan 85 set armor di save lengkap, semuanya cocok). Hanya ID 1–11 yang bertanda (perkiraan) karena namanya disusun dari pola set.

Nama equipment/jewel/skill memakai daftar mh4edit. Field relic khusus dikunci otomatis untuk equipment non-relic. Jangan mengubah field relic pada armor/weapon biasa: game dapat menghapus item yang tidak valid.

Isi nomor slot 1–1400 (sama dengan kolom Slot di tabel Equipment Box). Kosongkan kolom berarti tidak memakai item.

Set Armor

Sumber data: database MH4U.

Satu preset = satu set lengkap 5 bagian (Head, Body, Arms, Waist, Legs) dengan satu nama, dipisah antara Sword (Blademaster) dan Gunner. Pilih preset di daftar, lihat 5 potongannya di pratinjau, lalu tambahkan sekaligus. Potongan baru hanya diisi jenis dan ID; statistik, slot dan jewel dibiarkan kosong (diatur game dari ID-nya).

Ganti slot terpilih: pilih dulu satu slot armor di Equipment Box; slot itu diganti dengan potongan set yang jenisnya sama dan jewel di slot itu dikosongkan. Jika nama armor punya beberapa ID di daftar save, kolom ID di pratinjau berupa pilihan. Tanda ★ = ID itu memang ada di save asli; itu yang dipilih otomatis.

Koleksi Equipment

1.308 equipment dari save contoh. Armor dikelompokkan jadi preset set lengkap 5 bagian dengan satu nama (dipisah Sword dan Gunner), senjata dicari di tab sendiri. Ketuk + Tambah untuk menyalin ke slot kosong di Equipment Box. Data disalin utuh (jewel dan field relic ikut). Slot yang sudah terisi tidak pernah ditimpa.

Set Equipment Palico

15 set equipment dari Palico di save contoh (user1, user2, user3). Nama set = nama Palico asalnya. Yang disalin hanya data equipment (3 ID gear + 3 nomor slot gear + kotak gear Palico dari save contoh); nama, EXP, tampilan, dan data lain Palico tujuan tidak berubah. Nama gear tidak tersedia, jadi ditampilkan sebagai ID.

Catatan: nomor slot gear ikut disalin. Kalau di save tujuan slot itu berisi gear lain, gear yang terpasang bisa berbeda. Backup save dulu.

Koleksi Palico

79 Palico lengkap dari save contoh (user1, user2, user3). Pilih satu Palico, pilih slot Palico tujuan, lalu salin. Semua data Palico ikut disalin (nama, EXP, tampilan, skill, dan lainnya). Slot tujuan harus sudah berisi Palico.

Catatan: nama, EXP, tampilan, dan data lain Palico tujuan akan diganti seluruhnya. Kalau memilih ikut salin equipment, kotak gear Palico di save bisa diganti dan Palico lain yang memakai gear lama bisa jadi None. Backup save dulu.

Guild Quest Editor (WIP)

Hanya edit 10 slot quest yang sudah ada. Jangan buat quest baru atau menambahkan monster kedua pada quest yang belum memilikinya. Monster dan bias dipilih dari daftar mh4edit; nilai di luar daftar tetap dipertahankan (ditandai ?).
