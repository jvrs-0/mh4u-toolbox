Cara pakai & catatan
  1. Pilih file user1, lalu ketuk Unduh backup file asli.
  2. Zenny: ketuk Zenny maksimal (opsional).
  3. Item: pilih preset, isi Jumlah, ketuk Tambah preset.
  4. Equipment baru: ketuk Pilih slot kosong pertama, pilih Jenis dan nama, lalu Terapkan perubahan.
  5. Ketuk Simpan & unduh file, lalu impor di aplikasi.

Backup save dulu sebelum menimpa! Jika memindahkan satu file userX ke folder lain di 3DS, salin juga file lainnya (termasuk system), kalau tidak karakter/pengaturan bisa hilang.

Detail lanjutan equipment

Nama equipment/jewel/skill memakai daftar mh4edit. Field relic khusus dikunci otomatis untuk equipment non-relic. Jangan mengubah field relic pada armor/weapon biasa: game dapat menghapus item yang tidak valid.

Set Armor (dari database)

Pilih set armor dari database MH4U. Potongan baru hanya diisi jenis dan ID; statistik, slot dan jewel dibiarkan kosong (diatur game dari ID-nya).

Ganti slot terpilih: pilih dulu satu slot armor di Equipment Box; slot itu diganti dengan potongan set yang jenisnya sama dan jewel di slot itu dikosongkan. Jika nama armor punya beberapa ID di daftar save, kolom ID di pratinjau berupa pilihan. Tanda ★ = ID itu memang ada di save asli; itu yang dipilih otomatis.

Palico Editor

Edit nama dan EXP 56 Palico (1 utama, 5 aktif, 50 cadangan). Data lain dipertahankan.

Set Equipment Palico

15 set equipment dari Palico di save contoh (user1, user2, user3). Nama set = nama Palico asalnya. Yang disalin hanya data equipment (3 ID gear + 3 nomor slot gear + kotak gear Palico dari save contoh); nama, EXP, tampilan, dan data lain Palico tujuan tidak berubah. Nama gear tidak tersedia, jadi ditampilkan sebagai ID.

Catatan: nomor slot gear ikut disalin. Kalau di save tujuan slot itu berisi gear lain, gear yang terpasang bisa berbeda. Backup save dulu.

Guild Quest Editor (WIP)

Hanya edit 10 slot quest yang sudah ada. Jangan buat quest baru atau menambahkan monster kedua pada quest yang belum memilikinya. Monster dan bias dipilih dari daftar mh4edit; nilai di luar daftar tetap dipertahankan (ditandai ?).

Equipment yang sedang dipakai

Pilih nomor slot Equipment Box untuk loadout aktif.

Isi nomor slot 1–1400 (sama dengan kolom Slot di tabel Equipment Box). Kosongkan kolom berarti tidak memakai item.
